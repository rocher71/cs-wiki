:::tip[한 줄 요약]
필기 데이터통신은 **전송 방식·변조·다중화 짝 맞추기**와 **패리티·CRC·해밍 코드·섀넌·나이퀴스트·보오 계산**이 핵심이에요. 패리티·CRC는 **검출만**, 해밍 코드는 1비트 오류의 **위치까지 찾아 고쳐요**. 섀넌 공식 C = B·log2(1 + S/N)에는 dB가 아니라 **배수**를 넣어요.
:::

:::note[처음이라면 여기까지]
① 통신은 길 위의 자동차와 비슷해요. 일방통행(단방향), 한 차선 번갈아 쓰기(반이중), 왕복 2차선(전이중)이 있어요.

② 디지털 0·1을 전화선이나 전파에 실으려면 파도 모양을 바꿔요(변조). 높이를 바꾸면 ASK, 촘촘함을 바꾸면 FSK, 시작점을 바꾸면 PSK예요.

③ 오류는 "덤 비트"를 붙여 잡아요. 패리티는 1의 개수만 세고, CRC는 나눗셈 나머지를, 해밍은 여러 그룹을 겹쳐 오류 위치까지 알아내요.

④ 계산 문제는 공식 네 개로 거의 다 풀려요. 해밍 패리티 수, 섀넌, 나이퀴스트, bps = baud × 심볼당 비트. 아래 예제를 한 번씩 따라 해 보세요.
:::

## 쉽게 이해하기

친구에게 종이에 숫자를 적어 던져 준다고 해 봐요. 바람에 글자 하나가 번질 수 있어요.

가장 간단한 대비는 끝에 "1이 몇 개인지 짝수/홀수"를 적어 두는 거예요(패리티). 개수가 안 맞으면 "뭔가 틀렸다"는 건 알지만, 어디가 틀렸는지는 몰라요. 두 글자가 동시에 번지면 개수가 다시 맞아서 아예 못 알아채요.

해밍 코드는 확인 메모를 여러 장 쓰는데, 메모마다 담당하는 자리를 겹치게 나눠요. 어떤 메모들이 틀렸는지 조합을 보면 번진 자리 번호가 바로 나와요. 그래서 다시 보내 달라고 하지 않고 직접 고칠 수 있어요.

단, 실제 해밍(7,4)이 혼자 고칠 수 있는 건 **1비트 오류까지**예요. 2비트가 틀리면 엉뚱한 자리를 고칠 수 있어요.

## 개념 정리

### 통신 방식과 전송 모드

| 방식 | 뜻 | 예 |
|---|---|---|
| 단방향(Simplex) | 한쪽으로만 | 라디오, 옛 TV 방송, 키보드 → 컴퓨터 |
| 반이중(Half-Duplex) | 양쪽 다 보내지만 **동시에는 불가** | 무전기 |
| 전이중(Full-Duplex) | **동시에** 양방향 | 전화 |

- **병렬 전송**: n비트를 여러 선으로 한 번에. 빠르지만 선이 많아 비싸고 거리가 짧아야 해요.
- **직렬 전송**: 한 선으로 1비트씩. 먼 거리 통신의 기본이고, 다시 동기식·비동기식으로 나뉘어요.

| 구분 | 비동기식 | 동기식 |
|---|---|---|
| 단위 | **문자**(보통 1바이트) 하나씩 | **블록(프레임)** 단위로 묶음 |
| 맞추는 방법 | 문자마다 앞에 **스타트 비트**(0, 1개), 뒤에 **스톱 비트**(1, 1~2개) | 송수신이 클록을 맞춤. 문자 중심(SYN 문자)·비트 중심(플래그, 예: HDLC) |
| 문자 사이 간격 | 제각각 | 없음(연속) |
| 오버헤드 | 큼 | 작음 → 고속에 유리 |
| 쓰는 곳 | 모뎀, 저속 시리얼 | 고속 데이터 링크 |

비동기식 효율 예: 8비트 문자 + 스타트 1 + 스톱 1 = 10비트 중 데이터 8비트 → **80%**.

### 변조: 0·1을 파도에 싣기

**변조**(modulation)는 보낼 정보에 맞춰 **반송파**(carrier, 정보를 실어 나르는 기본 파도)의 모양을 바꾸는 거예요. 디지털 데이터를 아날로그 신호로 바꾸는 장치가 **모뎀**이에요.

| 데이터 → 신호 | 방식 | 바꾸는 것 |
|---|---|---|
| 디지털 → 아날로그 | ASK(진폭 편이) | 진폭(파도 높이) |
| 디지털 → 아날로그 | FSK(주파수 편이) | 주파수(파도 촘촘함) |
| 디지털 → 아날로그 | PSK(위상 편이) | 위상(파도 시작 위치) |
| 디지털 → 아날로그 | QAM(직교 진폭 변조) | **진폭 + 위상** 동시. 같은 대역에서 가장 많은 비트를 실어 고속 모뎀·Wi-Fi·케이블에 써요 |
| 아날로그 → 아날로그 | AM · FM · PM | 진폭 · 주파수 · 위상 |
| 아날로그 → 디지털 | PCM | 아래 3단계 |

### PCM 3단계

**PCM**(Pulse Code Modulation, 펄스 부호 변조)은 목소리 같은 아날로그 신호를 0·1로 바꿔요.

1. **표본화**(Sampling): 일정한 간격으로 값을 찍어요. 최고 주파수의 **2배 이상**으로 찍어야 원래 신호를 되살릴 수 있어요(나이퀴스트 표본화 정리).
2. **양자화**(Quantizing): 찍은 값을 정해진 계단 값 중 가장 가까운 것으로 반올림해요. 이때 생기는 차이가 **양자화 잡음**이에요.
3. **부호화**(Encoding): 계단 값을 2진수로 바꿔요.

받는 쪽은 복호화한 뒤 필터(여과)로 매끄럽게 되돌려요.

예: 전화 음성 최고 주파수 4kHz → 초당 8,000번 표본화 × 표본당 8비트 = **64kbps**.

### 다중화: 한 선을 여럿이 나눠 쓰기

**다중화**(multiplexing)는 회선 하나를 여러 채널이 함께 쓰게 하는 기술이에요.

| 방식 | 나누는 기준 | 특징 |
|---|---|---|
| FDM(주파수 분할) | 주파수 대역 | 채널 사이에 **보호 대역**(guard band)을 둬요. 라디오, 케이블 TV |
| 동기식 TDM(시분할) | 시간 슬롯을 채널마다 **고정** | 보낼 게 없어도 슬롯이 비어 낭비 |
| 통계적(비동기·지능형) TDM | 데이터 있는 채널에만 슬롯을 **동적 배정** | 효율이 좋지만 슬롯마다 어느 채널인지 **주소 정보**가 필요 |
| WDM(파장 분할) | 빛의 파장(색) | 광섬유용. 빛으로 하는 FDM |
| CDM/CDMA(코드 분할) | 채널마다 다른 코드 | 같은 시간·같은 주파수를 같이 쓰고 코드로 구분(확산 스펙트럼 계열) |

### 오류 검출과 정정 한눈에

모든 방법의 원리는 같아요. 데이터에 **중복 비트**(redundancy)를 덧붙여 받는 쪽이 검사해요.

| 방법 | 원리 | 검출/정정 | 주로 쓰는 곳 |
|---|---|---|---|
| 패리티(VRC) | 1의 개수를 짝수 또는 홀수로 맞추는 1비트 | 홀수 개 오류만 검출, **짝수 개 오류는 못 잡음**, 정정 불가 | 단순 문자 전송 |
| LRC / 블록 합 | 여러 바이트를 표로 놓고 가로·세로 양방향 패리티 | 한 방향이 놓친 오류를 다른 방향이 잡아 검출률 ↑ | 블록 전송 |
| 체크섬 | n비트씩 나눠 **1의 보수 덧셈** 후 보수 | 검출 | TCP·UDP·IP 헤더(상위 계층) |
| CRC | 생성 다항식으로 **모듈로-2 나눗셈(XOR)**, 나머지를 붙임 | 검출. **버스트 오류**(연달아 틀림)에 강함 | 데이터 링크(이더넷 CRC-32) |
| 해밍 코드 | 겹치는 패리티 그룹 여러 개 | **1비트 정정** | 메모리(ECC) 등 |

- **FEC**(전진 오류 수정): 받는 쪽이 스스로 고쳐요. 해밍, 컨볼루션 코드.
- **BEC / ARQ**(후진 오류 수정): 검출 후 다시 보내 달라고 해요. 재전송 방식은 [라우팅과 흐름·오류 제어](../routing-transport/)에서 봐요.

### 해밍 코드 규칙

- 비트 자리를 왼쪽부터 1, 2, 3 … 으로 번호 매길 때, **패리티 비트는 2의 거듭제곱 자리(1, 2, 4, 8 …)** 에 둬요. 나머지 자리에 데이터를 넣어요.
- 각 패리티는 자기 번호의 비트가 켜진 자리들을 묶어 **짝수 패리티**로 맞춰요. 7비트라면:
  - p1: 1, 3, 5, 7번 자리 (번호를 2진수로 썼을 때 1의 자리가 1)
  - p2: 2, 3, 6, 7번 자리 (2의 자리가 1)
  - p4: 4, 5, 6, 7번 자리 (4의 자리가 1)
- 데이터 m비트에 필요한 패리티 수 p는 **2^p ≥ m + p + 1**을 만족하는 가장 작은 값이에요. m = 4 → p = 3(해밍(7,4)), m = 8 → p = 4.

### 해밍 거리와 능력

**해밍 거리**(Hamming distance)는 두 코드에서 서로 다른 비트 수예요. 10110과 11100은 2, 4번째가 달라서 거리 2예요.

코드 집합의 **최소 해밍 거리**가 d일 때:

| 능력 | 공식 | d = 3 (해밍(7,4)) | d = 5 |
|---|---|---|---|
| 검출 가능 비트 | d − 1 | 2 | 4 |
| 정정 가능 비트 | ⌊(d − 1) / 2⌋ | 1 | 2 |

거꾸로 쓰면, s비트를 검출하려면 d ≥ s + 1, t비트를 정정하려면 d ≥ 2t + 1이 필요해요.

### 채널 용량과 속도 공식

| 공식 | 쓰는 상황 | 식 |
|---|---|---|
| 섀넌 용량 | **잡음 있는** 채널의 최대 전송률 | C = B · log2(1 + S/N) |
| 나이퀴스트 최대 전송률 | **잡음 없는** 채널, 신호 준위 M개 | C = 2B · log2 M |
| 보오와 bps | 심볼 하나에 log2 M비트 | bps = baud × log2 M |

- B는 대역폭(Hz), S/N은 신호 대 잡음비예요. 문제에 dB로 주면 **배수로 바꿔야** 해요. S/N(배) = 10^(dB / 10). 10dB = 10배, 20dB = 100배, 30dB = 1000배.
- **보오**(baud)는 1초에 신호가 몇 번 바뀌는지(심볼 수), **bps**는 1초에 몇 비트를 보내는지예요. 2진(M = 2)일 때만 둘이 같아요.
- 대역폭을 2배로 하면 C도 2배지만, S/N을 2배로 해도 로그라서 조금만 늘어요.

## 계산 예제

### 예제 1: 패리티 비트 붙이기

데이터 1010010을 **짝수 패리티**로 보내요.

1. 1의 개수: 1, 1, 1 → **3개**(홀수).
2. 전체 1의 개수를 짝수로 만들려면 패리티 = **1**.
3. 홀수 패리티였다면 이미 홀수라 패리티 = 0이에요.

### 예제 2: CRC 나머지 구하기

데이터 1101011011, 생성 다항식 x^4 + x + 1을 써요.

1. **다항식을 비트로**: x^4 + x + 1 = 1·x^4 + 0·x^3 + 0·x^2 + 1·x + 1 → **10011**. 최고 차수가 4라서 나머지는 4비트예요.
2. **0 붙이기**: 데이터 뒤에 0을 4개 → 11010110110000.
3. **모듈로-2 나눗셈**: 맨 앞이 1인 곳마다 10011을 맞대고 **XOR**(같으면 0, 다르면 1) 해요. 빼기 대신 XOR이라 자리 내림이 없어요.

```text
11010110110000
10011            ← 1번째 자리부터 XOR
-----
01001110110000
 10011           ← 2번째 자리
 -----
00000010110000
      10011      ← 7번째 자리
      -----
00000000101000
        10011    ← 9번째 자리
        -----
00000000001110   → 나머지 1110
```

4. **전송**: 원래 데이터 뒤에 나머지를 붙여 **11010110111110**을 보내요.
5. **수신 검사**: 받은 14비트를 같은 10011로 나누면 나머지가 0000이라 정상이에요. 0이 아니면 오류예요.

### 예제 3: 해밍(7,4) 만들고 오류 고치기

<Hamming74 />

데이터 **1011**을 해밍(7,4)로 보내요. 자리 배치는 왼쪽부터 p1 p2 d1 p4 d2 d3 d4예요.

**만들기**

1. **데이터 채우기**: 3번 = 1, 5번 = 0, 6번 = 1, 7번 = 1.
2. **p1**(1, 3, 5, 7): 3·5·7번은 1, 0, 1 → 1이 2개라 이미 짝수 → p1 = **0**.
3. **p2**(2, 3, 6, 7): 3·6·7번은 1, 1, 1 → 1이 3개 → 짝수로 맞추려면 p2 = **1**.
4. **p4**(4, 5, 6, 7): 5·6·7번은 0, 1, 1 → 1이 2개 → p4 = **0**.
5. **완성**: 자리 1~7 = 0 1 1 0 0 1 1 → **0110011**.

**오류 찾기**: 5번 비트가 뒤집혀 **0110111**을 받았어요.

| 검사 | 자리 | 받은 값 | 1의 개수 | 결과 |
|---|---|---|---|---|
| p1 그룹 | 1, 3, 5, 7 | 0, 1, 1, 1 | 3(홀수) | 틀림 → 1 |
| p2 그룹 | 2, 3, 6, 7 | 1, 1, 1, 1 | 4(짝수) | 맞음 → 0 |
| p4 그룹 | 4, 5, 6, 7 | 0, 1, 1, 1 | 3(홀수) | 틀림 → 1 |

6. **신드롬**: 틀린 그룹의 번호를 더해요. p4와 p1이 틀렸으니 4 + 1 = **5**. (p4 p2 p1 순서로 1 0 1 = 2진수 5)
7. **정정**: 5번 비트를 뒤집으면 0110011로 돌아와요. 신드롬이 0이면 오류 없음이에요.

<Aside type="caution" title="비트 번호 방향부터 확인하세요">
이 예제는 **왼쪽부터** 1번이에요. 그런데 일부 기출(교재의 국가직 유형)은 d4 d3 d2 p4 d1 p2 p1처럼 **오른쪽부터** 1번을 매겨요. 같은 7비트라도 방향이 다르면 패리티 값과 신드롬이 가리키는 자리가 달라져요. 문제의 배치 그림이나 "p1이 어디인지"를 먼저 보고 시작하세요.
</Aside>

### 예제 4: 섀넌 용량 (dB 변환 포함)

대역폭 3,000Hz, S/N = 30dB인 전화 회선의 최대 용량은요?

1. **dB → 배수**: 10^(30 / 10) = 10^3 = **1000**.
2. **공식에 넣기**: C = 3000 × log2(1 + 1000) = 3000 × log2(1001).
3. **로그 어림**: 2^10 = 1024라서 log2(1001) ≈ 9.97.
4. **답**: 3000 × 9.97 ≈ **29,900bps ≈ 30kbps**.

깔끔한 숫자 예: B = 4kHz, S/N = 15(배) → 4000 × log2 16 = 4000 × 4 = **16kbps**.

함정: 30dB를 그대로 넣어 log2(31)로 계산하면 틀려요.

### 예제 5: 나이퀴스트와 보오

1. **나이퀴스트**: 잡음 없는 대역폭 3,000Hz 채널에 신호 준위 4개(M = 4) → C = 2 × 3000 × log2 4 = 2 × 3000 × 2 = **12,000bps**.
2. **보오 → bps**: 16-QAM은 심볼이 16종류라 심볼 하나에 log2 16 = 4비트예요. 1,200baud면 1200 × 4 = **4,800bps**.
3. **반대로**: 9,600bps를 8-PSK(심볼당 3비트)로 보내면 9600 ÷ 3 = **3,200baud**예요.

## 객관식 함정

| 이렇게 나오면 | 왜 틀렸나 / 맞는 답 |
|---|---|
| "무전기는 전이중 방식" | 동시에 못 말하니 **반이중**. 전화가 전이중 |
| "TV 방송은 반이중" | 한쪽으로만 가니 **단방향** |
| "비동기식은 블록 단위, 동기식은 스타트·스톱 비트" | 반대. 비동기 = **문자 + 스타트·스톱 비트**, 동기 = 블록 + 클록 |
| "QAM은 진폭과 주파수를 함께 바꾼다" | **진폭 + 위상** |
| "PCM 순서는 양자화 → 표본화 → 부호화" | **표본화 → 양자화 → 부호화** |
| "표본화는 최고 주파수의 절반 이상이면 된다" | **2배 이상** |
| "양자화 잡음은 표본화 단계에서 생긴다" | 반올림하는 **양자화** 단계 |
| "동기식 TDM은 데이터 있는 채널에만 슬롯을 준다" | 그건 **통계적 TDM**. 동기식 TDM은 고정 배정이라 빈 슬롯 낭비 |
| "패리티는 홀수 개 오류를 검출하지 못한다" | 반대. **짝수 개** 오류를 못 잡아요 |
| "CRC는 오류를 정정한다" | 패리티·CRC·체크섬은 **검출만**. 정정은 해밍 |
| "CRC는 1의 보수 덧셈" | 1의 보수 덧셈은 **체크섬**. CRC는 **XOR(모듈로-2)** 나눗셈 |
| "해밍 패리티 비트는 1, 3, 5, 7번 자리" | 패리티는 **1, 2, 4, 8**(2의 거듭제곱). 1, 3, 5, 7은 p1이 검사하는 그룹 |
| "최소 해밍 거리 3이면 3비트 정정" | 정정 ⌊(3 − 1)/2⌋ = **1비트**, 검출 2비트 |
| "S/N 30dB면 log2(1 + 30)" | dB를 배수로: **1000** |
| "섀넌은 잡음 없는 채널, 나이퀴스트는 잡음 있는 채널" | 반대. **섀넌 = 잡음 있음**, 나이퀴스트 = 잡음 없음 |
| "보오와 bps는 항상 같다" | 심볼당 1비트(M = 2)일 때만 같아요 |

## 연습 문제

<details>
<summary>1. 양쪽 모두 송수신할 수 있지만 한 번에 한쪽만 보낼 수 있는 방식은? ① 단방향 ② 반이중 ③ 전이중 ④ 병렬</summary>

**정답: ②**

무전기처럼 번갈아 말하는 방식이 반이중이에요. 전이중은 동시에 양방향(전화), 단방향은 한쪽으로만(라디오)이에요. 병렬은 전송 방식이 아니라 선 여러 개로 한 번에 보내는 전송 모드예요.
</details>

<details>
<summary>2. 데이터 1011001에 홀수 패리티 비트를 붙이면 패리티 값은? ① 0 ② 1 ③ 3 ④ 붙일 수 없다</summary>

**정답: ②**

1의 개수는 1, 1, 1, 1 → 4개(짝수)예요. 전체를 홀수로 만들려면 패리티 = 1을 붙여요. 짝수 패리티였다면 0이에요.
</details>

<details>
<summary>3. 데이터 비트가 8개일 때 1비트 오류를 정정하는 해밍 코드에 필요한 패리티 비트 수는? ① 3 ② 4 ③ 5 ④ 8</summary>

**정답: ②**

2^p ≥ m + p + 1에 m = 8을 넣어요.
1. p = 3: 2^3 = 8, 8 + 3 + 1 = 12 → 8 ≥ 12 아님.
2. p = 4: 2^4 = 16, 8 + 4 + 1 = 13 → 16 ≥ 13 성립.

그래서 4개, 전체 12비트 코드가 돼요.
</details>

<details>
<summary>4. 해밍(7,4) 코드(왼쪽부터 1번, 배치 p1 p2 d1 p4 d2 d3 d4, 짝수 패리티)로 0101100을 받았어요. 오류가 난 비트 위치는? ① 2번 ② 3번 ③ 5번 ④ 오류 없음</summary>

**정답: ②**

1. p1 그룹(1, 3, 5, 7): 0, 0, 1, 0 → 1이 1개(홀수) → 1
2. p2 그룹(2, 3, 6, 7): 1, 0, 0, 0 → 1이 1개(홀수) → 1
3. p4 그룹(4, 5, 6, 7): 1, 1, 0, 0 → 1이 2개(짝수) → 0
4. 신드롬 = 2 + 1 = 3 → 3번 비트 오류예요.

3번을 뒤집으면 0111100이고, 데이터(3·5·6·7번)는 1100이에요.
</details>

<details>
<summary>5. 어떤 코드의 최소 해밍 거리가 5일 때, 정정할 수 있는 최대 오류 비트 수는? ① 1 ② 2 ③ 4 ④ 5</summary>

**정답: ②**

정정 가능 비트 = ⌊(5 − 1) / 2⌋ = 2예요. ③ 4는 검출 가능 비트(d − 1)예요.
</details>

<details>
<summary>6. 대역폭 1MHz, 신호 대 잡음비 20dB인 채널의 섀넌 용량에 가장 가까운 값은? ① 약 4.4Mbps ② 약 6.7Mbps ③ 약 20Mbps ④ 약 100Mbps</summary>

**정답: ②**

1. 20dB → 10^(20/10) = 100배.
2. C = 1,000,000 × log2(1 + 100) = 1,000,000 × log2(101).
3. 2^6 = 64, 2^7 = 128이라 log2(101) ≈ 6.66.
4. C ≈ 6.66Mbps예요.

① 4.4Mbps는 dB를 그대로 넣은 log2(21) ≈ 4.39로 계산한 함정이에요.
</details>

<details>
<summary>7. 잡음이 없는 대역폭 4kHz 채널에서 신호 준위 8개를 쓸 때 나이퀴스트 최대 전송률은? ① 8kbps ② 12kbps ③ 24kbps ④ 32kbps</summary>

**정답: ③**

C = 2B · log2 M = 2 × 4000 × log2 8 = 2 × 4000 × 3 = 24,000bps예요. ① 8kbps는 log2 M을 빠뜨린 값이에요.
</details>

<details>
<summary>8. 16-QAM으로 2,400baud의 신호를 보낼 때 전송 속도는? ① 600bps ② 2,400bps ③ 9,600bps ④ 38,400bps</summary>

**정답: ③**

16-QAM은 심볼이 16종류라 심볼 하나에 log2 16 = 4비트예요. 2400 × 4 = 9,600bps예요. ④ 38,400은 4비트 대신 16을 곱한 함정이에요.
</details>

## 면접 질문

<details>
<summary>Q. 패리티, 체크섬, CRC는 어떻게 다르고 각각 어디서 쓰나요?</summary>

**답변(30초)** 셋 다 덧붙인 비트로 오류를 검출만 하고 고치지는 않아요. 패리티는 1의 개수만 맞추는 1비트라 짝수 개 오류를 못 잡아요. 체크섬은 1의 보수 덧셈으로 TCP·UDP·IP 헤더 같은 상위 계층에서 쓰고, CRC는 다항식 나눗셈 나머지로 버스트 오류에 강해서 이더넷 같은 데이터 링크 계층에서 써요. 그래서 이더넷이 CRC로 깨진 프레임을 버리면, 다시 보내는 일은 TCP가 맡아요.

**꼬리질문**
- Q. 오류를 직접 고치는 방법은? → 해밍 코드 같은 FEC예요. 서버 ECC 메모리가 해밍 계열 코드로 1비트 오류를 자동으로 고쳐요.
- Q. 와이파이 신호가 약해지면 속도가 떨어지는 이유는? → S/N이 낮아지면 촘촘한 QAM을 구분하기 어려워 심볼당 비트가 적은 변조로 낮춰요. 섀넌 공식에서도 S/N이 줄면 용량이 줄어요.
</details>
